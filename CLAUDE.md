# sprint-standards

Agent standards and sprint workflow definitions. Import into your project's AGENTS.md via `@` lines.

## Files

- `efficiency.md` — coding standards, git conventions, token-efficiency rules
- `skill-setup-std.md` — rules for writing and organizing skill files
- `sprint-workflow.md` — sprint lifecycle: tiers, dispatch, close gates

## Usage

Reference these with `@`-imports in your AGENTS.md:

```
@path/to/standards/efficiency.md
@path/to/standards/sprint-workflow.md
```
