# sprint-standards

Agent coding standards, skill setup conventions, and sprint workflow definitions. Import via `@` lines in your AGENTS.md.

## Files

- `efficiency.md` — coding, git, token-efficiency rules
- `skill-setup-std.md` — rules for writing skill files
- `sprint-workflow.md` — sprint lifecycle: tiers, dispatch, close gates

## Usage

```
@path/to/sprint-standards/efficiency.md
@path/to/sprint-standards/sprint-workflow.md
```
